# Instapro

Реализована регистрация и авторизация с обработкой ошибок, сохранением токена и переходом на ленту.

Посты загружаются с API и динамически отображаются на странице.

Пост добавляется с фото и описанием, отображается сразу.

Переход по имени открывает ленту конкретного пользователя.

HTML-теги экранируются, не срабатывают в интерфейсе.

Интерфейс адаптивный и соответствует макету.

Маршруты работают без перезагрузки, структура логична.

Формы валидируются, ошибки показываются корректно.

Все участки с @TODO реализованы, структура кода сохранена.

Примечание: Не работают изображения лайков, хотя путь правильный (assets/images/)
